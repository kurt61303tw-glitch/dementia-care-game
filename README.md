## 二、如何開啟與體驗

### 方式 A：本機直接體驗「單人練習」與「師長＋學員雙視窗多人同步」
1. 直接用瀏覽器（Chrome / Edge）打開 [index.html](file:///D:/Wang%20AI%20agent/400_Project/dementia-care-game/index.html)。
2. **單人練習**：在兩大主題門點選「🌱 單人自主練習（3A）」，即可自由選擇單元開始作答。
3. **同台電腦體驗多人開房與 ABCD 人數分佈**：
   - 點選「👩‍🏫 師長開房（多人掃碼答題）」進入等候室。
   - 點擊右上角「**📱 開啟『學員手機模擬視窗』測試**」，會自動彈出學員手機端視窗並帶入 6 碼安全房號與簽章 Token。
   - 在學員視窗輸入暱稱加入後，師長端會即時顯示學員入房；師長按下「開始第一題」，學員按 A/B/C/D，師長按「揭曉」即可看到布告欄 ABCD 人數分佈與答錯解析！

### 方式 B：跨手機真實掃描 QR Code 連線（4B 託管雲端設定步驟）
由於手機掃描 QR Code 必須連線至公開或區網的 `http(s)://` 網址（手機無法讀取電腦本機 `file://` 路徑）：
1. 將 `dementia-care-game` 資料夾免費部署至 **GitHub Pages**、**Vercel** 或 **Cloudflare Pages**。
2. 前往免費的 [Firebase Console](https://console.firebase.google.com/) 建立一個 Realtime Database，將其 URL（如 `https://your-project-default-rtdb.firebaseio.com`）複製起來。
3. 點擊網站右上角「**☁️ 雲端連線設定**」，貼上 Firebase Realtime Database URL 並儲存，全班學員即可用各自手機掃描 QR Code 跨網段即時作答！
